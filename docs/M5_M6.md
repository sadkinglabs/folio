# M5 and M6: the contract for four parallel workstreams

**Status (2026-10-17): the four workstreams are built and integrated in the working tree on `redesign` (not committed yet). §9 lists where the code differs from this contract.**

Base: branch `redesign`, HEAD `f88c3c5` (CI green). Room schema 11. Owner decisions are in `docs/UPGRADE_PLAN.md` under M5 and M6; this file turns them into four workstreams that can run at the same time:

| Workstream | Builds |
|---|---|
| **acquire** | All of M5: book sources, the in-app browser and its download catcher, DRM detection, import and attach, open/share intents. |
| **reader** | In-book search, time left, the offline dictionary (download, lookup, lemmatiser, Define sheet), the selection menu, and the reader's max text width and two-page spread. |
| **adaptive** | Tablet and foldable layouts for every non-reader screen, the accessibility pass on those screens, a Licences sheet in Settings. |
| **data** | Revision pruning, typed errors, safe hardening, its tests, and the docs (`UPGRADE_PLAN.md` status, `THIRD_PARTY.md`). |

One change from the brief: **the reader's max width and two-page spread move from adaptive to reader.** They live in `ReaderViewModel.preferences()` and `ReaderActivity.mount()`, and those files must have one owner. Adaptive does not touch `reader/`.

## 0. Rules for every workstream

1. **Compile alone.** Each branch must build and pass the checks on its own. Nothing calls a symbol that only exists on another branch. The few cross-branch calls use the seams in §2, which compile without the other side.
2. **Disjoint files.** Edit only the files you own (§1). If you need a change in someone else's file, it is either in this contract already or it waits for the integration step (§7). New files go under your own paths.
3. **Frozen signatures.** Anything listed in §2.3 as used across a boundary keeps its name, parameters and behaviour. Additive changes only: new parameters at the end with defaults, new fields with defaults, new functions.
4. **CLAUDE.md invariants hold.** minSdk 36, package `dev.sadking.folio`. **No Room schema change in M5/M6** (stays at 11; see §6). Never discard annotations or reading data. Never silently overwrite a book file. A missing file is never a deletion. A book record can exist without a file. Never log credentials, tokens, URLs with query strings, or book text (this includes selected words and search queries).
5. **Strings.** All UI copy goes in your own string file: `strings_m5_acquire.xml` (prefix `acq_`), `strings_m6_reader.xml` (`rd6_`), `strings_m6_adaptive.xml` (`ad6_`), `strings_m6_data.xml` (`data6_`). Plain, short English. Existing string files: see §1.5.
6. **No new third-party library.** None is needed (§5). Adaptive declares `androidx.window:window:1.5.0`, which is already on the runtime classpath through Compose.
7. **Checks before handing off:**
   ```sh
   ./gradlew formatKotlin
   ./gradlew checkFormatting :core:test :transport:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
   ./gradlew :app:testDebugUnitTest --tests '*ScreenshotTest' -Pscreenshots   # look at your PNGs in app/build/screenshots
   ```
   Instrumented tests (`connectedDebugAndroidTest`) run in CI's emulator; run yours locally only if an emulator is available.
8. **Report honestly.** Your final report lists each feature with its verification level: *executed on a real device*, *executed in the emulator or JVM*, *compiled only*, *not verified*. A Robolectric or mocked test is never "works on a device".
9. **Git.** Commit as `sadkinglabs <jessonio.home@gmail.com>`. No Claude author, no `Co-Authored-By: Claude`, no session trailers (CLAUDE.md wins over any tool default). One branch per workstream: `m56-acquire`, `m56-reader`, `m56-adaptive`, `m56-data`, each from `f88c3c5`.

### 3.3 Catching and importing downloads

`WebView.setDownloadListener`. Sniffing is a pure function, JVM-tested:

```kotlin
package dev.sadking.folio.acquire

enum class DownloadKind { BOOK, ACSM, OTHER }

object DownloadSniffer {
    /** From the MIME type, the Content-Disposition file name, and the URL path's extension. */
    fun kind(url: String, contentDisposition: String?, mimeType: String?): DownloadKind
    /** A safe file name: no path parts, no control characters, no leading dots, at most 120 characters. */
    fun fileName(url: String, contentDisposition: String?, mimeType: String?): String
}
```

BOOK: MIME `application/epub+zip`, `application/pdf`, `application/x-pdf`, `application/vnd.comicbook+zip`, `application/x-cbz`, `application/vnd.comicbook-rar`, `application/x-cbr`; or extension `epub`, `pdf`, `cbz`, `cbr` (also with `application/octet-stream`, `application/zip`, `application/x-rar-compressed`). ACSM: MIME `application/vnd.adobe.adept+xml` or extension `acsm` (never downloaded; say "protected" at once). OTHER: say "Not a book Librillo can open" and do nothing. The bytes decide in the end (`BookFormats`), as for any import.

Download (`BookDownloader`, `HttpURLConnection`, https only, redirects followed only to https): send the WebView's cookies (`CookieManager.getCookie(url)`), its user agent, and the page as `Referer`. Refuse when `Content-Length` > `Epub.MAX_FILE` or the bytes pass it (`TooLargeBook` path). Runs in a process-wide scope owned by acquire (an `object` with a `SupervisorJob`, like `KokoroModel`), so leaving the browser does not cancel it; "Stop" cancels and deletes the partial file.

Where the bytes go. In both cases, once the download is complete and before anything is imported, run `BookFormats.detect` and `BookProtection.check` (§3.4); a protected file is deleted and reported, never imported.

1. **Books folder ready** (`repo.folderReady()`): stream to `<booksRoot>/Inbox/.download-<uuid>.part` (hidden: the Inbox pass and the folder scan skip dot files). When complete and checked: `setLastModified(now)` (so the Inbox pass treats it as still settling); rename to `BooksInbox.freeName(inbox, safeName)`; call `repo.fileFromInbox(file)` at once. New book: done (the file was renamed into `Author/Title.<format>`). Already in the library (`false`): delete the downloaded copy, which is byte-identical to a book already kept. If the app dies between the rename and the import, the next Inbox pass files it, which is the point of staging there.
2. **Folder not ready**: stream to `cacheDir/downloads/<uuid>/<safeName>` and call `repo.import(Uri.fromFile(file))` (the name in the URI keeps the format hint and the title fallback); delete the cache folder afterwards.

`NotABook`, `UnreadableBook`, `TooLargeBook` from the repository: delete the download, say the plain message. Never write over an existing file (`freeName`, `Files.move` without `REPLACE_EXISTING`).

**Attach.** With a `WISH_ID`, after a new or existing book: `repo.attach(wishId, book.id)`. Its `require` messages are already plain; show them. The record page in the app turns into the book page on its own (`FolioApp`'s `LaunchedEffect(catalogue?.linkedBookId)`).

### 3.4 DRM detection (core, pure JVM)

```kotlin
package dev.sadking.folio.core

enum class Protection { NONE, ADOBE, LCP, APPLE, ENCRYPTED, PDF_DRM }

object BookProtection {
    /** An Adobe ACSM fulfilment token: by MIME type, `.acsm` name, or `<fulfillmentToken` in the adept namespace in the first bytes. */
    fun isAcsm(header: ByteArray, fileName: String?, mimeType: String?): Boolean
    /** [format] is a `BookFormats` value. CBZ and CBR are always NONE. */
    fun check(file: File, format: String): Protection
}
```

EPUB: `META-INF/rights.xml` → ADOBE; `META-INF/license.lcpl` → LCP; `META-INF/sinf.xml` → APPLE; `META-INF/encryption.xml` → ENCRYPTED if any `EncryptionMethod/@Algorithm` is not font obfuscation (`http://www.idpf.org/2008/embedding`, `http://ns.adobe.com/pdf/enc#RC`), or if the file can't be parsed (bounded read ≤ 1 MB, XML parser with DOCTYPE disallowed). PDF: an `/Encrypt` dictionary whose `/Filter` is not `/Standard` (e.g. `/EBX_HANDLER`, `/Adobe.APS`, `/FOPN_…`) → PDF_DRM; scan the first 64 KB and last 1 MB only. Anything not NONE → "This book is protected (DRM) and can't be opened".

This is used for browser downloads only in M5. Using it for every import is a follow-up (§8).

### 4.3 reader: offline dictionary

**Data: Open English WordNet 2025+ (WNDB format), CC BY 4.0, derived from Princeton WordNet 3.1 under the WordNet licence.** Checked on 2026-10-17:

| | |
|---|---|
| URL | `https://github.com/globalwordnet/english-wordnet/releases/download/2025-edition/english-wordnet-2025-plus.zip` |
| Size | 10,982,041 bytes |
| SHA-256 | `cf4afe7ad4cca3f56091d791e665614c564ac84e3782de4e789cf5b745556e2e` |
| Range requests | supported (HTTP 206), so the download can resume |
| Top folder | `oewn2025-plus/` |
| Keep (12 files, 29,467,576 bytes) | `index.noun`, `index.verb`, `index.adj`, `index.adv`, `data.noun`, `data.verb`, `data.adj`, `data.adv`, `noun.exc`, `verb.exc`, `adj.exc`, `adv.exc` (drop `index.sense`) |

Use this GitHub release asset only. en-word.net serves a rebuilt zip with a different hash. "2025+" includes curated proper nouns (London, Shakespeare), so coverage is like earlier releases; the plain "2025" edition drops them. Rejected: Wiktionary extracts (CC BY-SA, hundreds of MB), Princeton WordNet 3.1 (older, unmaintained).

Format facts (checked on the file): every index and data file starts with 29 licence lines that begin with two spaces; skip them. After them, index lines are sorted by bytes (C locale), so lookups are a binary search with `RandomAccessFile`; a line that starts with two spaces counts as smaller than any key. Index line: `lemma pos synset_cnt p_cnt [ptr…] sense_cnt tagsense_cnt offset…` (offsets are 8-digit byte offsets into `data.<pos>`). Data line: `offset lex_filenum ss_type w_cnt word lex_id … p_cnt [ptr…] [frames] | gloss`; `w_cnt` is hex; `ss_type` `s` is an adjective satellite; adjective words may carry `(a)`, `(p)`, `(ip)`, which you strip. Gloss: the definition is the text before the first `; "`; examples are the quoted parts. Text is UTF-8 with curly quotes. Lemmas are lower case with `_` for spaces. Longest data line is 35,220 bytes.

Pure JVM in `core`:

### 4.10 data: revision pruning

```kotlin
package dev.sadking.folio.data

data class PruneResult(val removed: Int = 0, val bytes: Long = 0, val skipped: Int = 0)

/**
 * Keeps each book's original, its current file and the [keepPrevious] newest previous revisions;
 * removes older previous revisions and superseded covers. Never touches database rows.
 */
class RevisionPruner(
    private val repo: LibraryRepository,
    private val keepPrevious: Int = 3,
) {
    /** One book. Call with `repo.lock` held. */
    internal suspend fun pruneLocked(bookId: String): PruneResult
    /** Every book, one at a time under the lock. */
    suspend fun pruneAll(): PruneResult
}
```

What counts as a previous revision (and nothing else): `<booksRoot>/.librillo/previous/<bookId>-<millis>.<format>` (exact pattern, so one id is never the prefix of another), and in `filesDir/library/<bookId>/` files named `<uuid>.<format>` and covers named `cover-<uuid>`.

Never removed: any path held by any `books` row (`originalPath`, `currentPath`, `coverPath`) across all books, including those in Recently removed; anything in `.librillo/originals/`; `original.<format>`; `cover-original`; any file outside those two folders.

Skip a book entirely (count it in `skipped`) when it is in Recently removed, when its current file is missing, or when the current file's SHA-256 is not `currentHash`. In those cases a previous revision may be the only good copy left.

When: inside the lock right after a revision commits (`reviseLocked`, `editInFolder`, private-storage `edit`), in `NonCancellable`, never failing the edit (errors are counted, not thrown); and `pruneAll()` at most once a day from `LibraryViewModel.refreshFolder`. Phone positions and bookmarks for old revisions stay in Room (they are reading data). Backups are unaffected: they only carry files the rows point at.

- **DAO split**: no concrete benefit now.
